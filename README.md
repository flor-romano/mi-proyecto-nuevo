# Placas animadas para videotutoriales (Remotion)

- `src/config.ts` — textos, colores, tiempos (en segundos) y movimientos editables.
- `src/PlacaIntro.tsx` — la placa animada (1920x1080, 30 fps, 4 s).
- `videos/placa-intro.mp4` — render final.

## Uso

```bash
npm install
npm run studio   # previsualizar y ajustar
npm run render   # genera videos/placa-intro.mp4
```
